# 划词即听 · Word Speaker

一个 macOS 菜单栏工具。选中 `project` 之类的英文单词或短句，松开鼠标后即可听到发音。支持能通过 macOS 辅助功能提供选区的浏览器、PDF 阅读器和文档应用。

- 可切换美音和英音、选择已安装的系统声音、试听和调节语速。自动模式优先使用已安装的「优质」或「增强」声音。
- 支持暂停自动朗读、重读上一段和手动朗读剪贴板。
- 使用 macOS 在本机生成语音。选中文字不会上传，应用不会把划词历史写入磁盘。

## 构建与运行

应用的最低部署版本为 macOS 13。构建需要 Apple 命令行开发工具或 Xcode，并且所用的 macOS SDK 至少为 14。项目没有第三方依赖。

在本目录运行：

```sh
zsh build.sh
open "dist/划词即听·声音版.app"
```

脚本按当前机器架构编译，并对生成的应用做本地临时签名。请在需要使用它的 Mac 上构建。

## 使用方法

1. 在试读窗口双击 `project`，确认能自动发音。
2. 要在其他应用中划词，点击「打开权限设置」，在「系统设置 → 隐私与安全性 → 辅助功能」中开启「划词即听·声音版」。若列表里没有该应用，点 `+` 添加刚构建的 `.app`。
3. 等应用显示绿色的「全局划词已就绪」，再到其他应用选中一个英文单词试用。关闭试读窗口后仍可通过菜单栏的扬声器图标管理应用。

如果重新构建后授权失效，在系统设置中移除旧条目，添加当前的 `.app` 并重新打开应用。想确认权限是否生效，可以先用 macOS 自带的「文本编辑」测试。

自动朗读支持含英文的短选区，最多 160 个字符和 20 个词。部分页面和阅读器不会提供可读取的选区。此时可先按 `⌘C` 复制，再从菜单栏选择「朗读剪贴板」。图片和扫描版 PDF 需要先识别成可选文字。

## 更换声音

在「设置与试读」中选美音或英音，再从「声音」下拉菜单选择一个声音，并点击「试听声音」。安装更多语音可前往「系统设置 → 无障碍 → 阅读与朗读 → 系统声音」。下载完成后回到应用点「刷新列表」，即可离线使用。[Apple 语音下载说明](https://support.apple.com/zh-cn/guide/mac-help/mchlp2290/mac)

## 测试

```sh
zsh test.sh
```

在 macOS 图形会话中，构建后可以运行 `zsh test.sh --ui`。它在后台创建试读窗口，验证选中 `project` 后系统是否用选定的声音开始朗读。测试会短暂发声，无需开启辅助功能权限。
